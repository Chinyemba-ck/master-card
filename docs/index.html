How It Works

1

Ingest IGS Data

Pull Mastercard IGS scores for any census tract — 83,355 tracts nationwide, updated annually.

2

Train the Model

Ridge regression (R²=0.935) and Gradient Boosting (R²=0.956) identify which indicators drive overall IGS.

3

Benchmark & Gap

Compare any community against national and state distributions. Quantify the gap to aspirational peers.

4

Prioritize Levers

Cross-reference model weights, historical correlation, and gap size to surface the top 5 actionable interventions.
